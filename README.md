🩺 Skin Disease Detection using Deep Learning & Streamlit
This project is a web-based skin disease classification system built with TensorFlow (Keras) and Streamlit. It uses a fine-tuned MobileNetV2 model to identify common skin diseases from uploaded images and provides health tips, prevention measures, and cure suggestions based on the prediction.

🔍 Features
📷 Upload an image of a skin lesion and get an instant diagnosis.

🧠 Deep learning model trained on a custom skin disease dataset using MobileNetV2.

✅ Real-time predictions with high accuracy.

🧴 Health tips for Acne, Eczema, and Melanoma, including:

Prevention methods

Cure recommendations

Trusted resource links

💾 Model training with data augmentation and checkpoint saving.

🌐 Clean and interactive UI using Streamlit.

🧠 Technologies Used
TensorFlow & Keras

MobileNetV2 (Transfer Learning)

OpenCV & PIL for image preprocessing

NumPy

Streamlit for the web interface
